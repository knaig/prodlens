prodlens

Discovers a web app's UI as a graph of screens and transitions, prioritizes critical user journeys, executes them with Playwright, and reports broken edges, dead ends, and missing return paths.

Why

AI-assisted UIs accumulate a specific failure mode: buttons that render but do nothing, links to routes that no longer exist, screens nobody wired into navigation. Normal dev/test loops check "does this one flow work" - nothing checks "is every edge functional across the whole graph." This tool does.

Two discovery passes

Static AST scan (no browser, no server) plus a live Playwright crawl that reads the real rendered DOM and clicks real elements.

Form-aware execution

Detects <form>-less input clusters by viewport, fills them like a user, and only then clicks submit - so disabled-until-valid buttons aren't misreported as broken.

Video for every journey

Replay any prioritized path to a .webm, assemble run screenshots into an MP4, or record the screen while you drive the explorer.

The demo

Below is a live-crawled graph of lazy-dist (a Next.js app): 25 screens, plus the prioritized journeys and run results. The Projects tab in the explorer surfaces the reports, specs, screenshots, and journey videos in-tool.

Quick start

npm install
npx playwright install chromium

# static pass (no server)
prodlens scan --app-dir /path/to/app/src/app --name my-app

# full pipeline: discover -> prioritize -> run -> report
prodlens full --base-url http://localhost:3000 --name my-app

# record one journey as video
prodlens capture --paths data/paths.json --graph data/versions/<id>.json --base-url http://localhost:3000
